❓ Cómo activar la sincronización en la nube
  1. Entra a console.firebase.google.com con una cuenta de Google y crea un proyecto nuevo (gratis).
  2. En el menú lateral, entra a Realtime Database y presiona "Crear base de datos". Elige la ubicación y comienza en modo de prueba (más abajo dejamos las reglas permanentes).
  3. En el menú lateral, entra a Authentication → pestaña "Sign-in method" → habilita el proveedor Anónimo. Esto permite identificar a cada PC sin pedir contraseña a nadie.
  4. En Realtime Database → pestaña "Reglas", reemplaza el contenido por esto y presiona "Publicar" (así deja de caducar a los 30 días): 
    {
  "rules": {
    "sucursales": {
      ".read": "auth != null",
      "$sucursalId": {
        ".write": "auth != null"
      }
    },
    "dispositivos": {
      ".read": "auth != null",
      "$deviceId": {
        ".write": "auth != null"
      }
    },
    "facturas_data": {
      "$sucursalId": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    },
    ".read": false,
    ".write": false
  }
}
  5. En el menú lateral, entra a Configuración del proyecto (el ícono de engranaje) → pestaña "General".
  6. Baja hasta "Tus apps", presiona el ícono </> (Web) y registra una app (no necesita Firebase Hosting).
  7. Firebase te mostrará un bloque de código con apiKey, databaseURL y projectId. Copia esos 3 valores y pégalos aquí, en "Ajustes generales".
  8. Repite este pegado de los mismos 3 datos en las 3 PC (Ceibos, Carlos Julio y Daule) para que las tres se conecten al mismo proyecto.

Esta configuración solo se hace una vez por proyecto (los pasos 1 a 4) y una vez por PC (los pasos 5 a 8). Con las reglas del paso 4, la sincronización queda funcionando de forma permanente, sin caducar.
